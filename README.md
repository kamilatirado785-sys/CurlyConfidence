# CurlyConfidence Website

This is a functional, lightweight version of the CurlyConfidence site based on the Framer screenshots you provided.

## Included functionality
- Responsive navigation
- Working section links
- English / Spanish toggle for the main content
- Hair-type selection cards with personalized starting guidance
- 5-question interactive hair quiz with a result
- Resource-library search
- Tutorial/guide modals
- Interactive "Build My Curl Routine" activity
- Contact inquiry form that prepares an email
- Your uploaded CurlyConfidence logo is already included

## Important before launch
1. Replace the "ADD MY OWN PHOTO HERE" areas with your own photos.
2. Replace "ADD MY VIDEO HERE" with your actual videos.
3. Change the `mailto:` line in `script.js` to your actual public CurlyConfidence contact email, or connect the form to Formspree/another form backend.
4. Review all educational content before publishing. This site is designed as an educational resource, not a medical diagnostic tool.
5. If you want a true multi-page site, the current sections can be split into separate routes/pages later.

## Easiest deployment
This is plain HTML/CSS/JavaScript, so it can be deployed to Cloudflare Pages, GitHub Pages, Netlify, or another static host without a build step.

Open `index.html` locally to test it, or upload the whole folder to a static hosting service.
